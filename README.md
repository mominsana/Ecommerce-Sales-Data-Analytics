# Ecommerce-Sales-Data-Analytics
# File Location: https://drive.google.com/drive/folders/15sqgCwmGJpPazm9cIsdH3fXZEaWP8EiB?usp=sharing
Project Info:
This project analyzes the Olist Brazilian E-commerce Dataset to uncover sales, product, seller, customer, and delivery performance insights using Power BI. The project demonstrates a complete analytics workflow including data preparation, modeling, DAX calculations, interactive dashboards, and business storytelling.

Project Objective: 
  1. Analyze overall sales and revenue performance.
  2. Identify top products and sellers contributing to revenue.
  3. Understand customer purchasing behavior.
  4. Evaluate delivery performance and its impact on customer reviews.
  5. Build an interactive, multi-page Power BI dashboard with smooth navigation.

Business Objectives:
  1. Analyze overall sales performance and revenue trends.
  2. Understand customer behavior and purchasing patterns
  3. Evaluate order fulfillment and delivery performance
  4. Identify top products, sellers, and categories
  5. Assess payment methods and order value distribution

Tools & Technologies:
  1. Power BI – Data modeling, DAX measures & dashboards
  2. Power Query – Data cleaning and transformation
  3. Microsoft Excel – Initial exploration

Dashboard Highlights:

🔹 Overview Page
  1. Total Revenue, Orders & AOV KPIs
  2. Sales trend analysis (Monthly / Yearly)
  3. Payment method distribution

🔹 Product & Seller Page
  1. Category-wise revenue and quantity analysis
  2. Top-performing products and sellers
  3. Seller contribution to total sales

🔹 Customer & Delivery Page
  1. Customer order behavior
  2. Average delivery time & on-time delivery %
  3. Impact of delivery delays on review scores

Key Insights:
  1. A small number of product categories generate the majority of total revenue
  2. Top sellers significantly outperform the average seller in sales contribution
  3. Credit cards are the most commonly used payment method
  4. Delayed deliveries have a strong negative impact on customer review scores


How to Use This Project:
  1. Open the GitHub repository
  2. Access the Google Drive link shared in the repository (public access)
  3. Download the complete project folder containing:
  4. All required CSV files (Olist dataset)
  5. The Power BI (.pbix) dashboard file
  6. Keep all CSV files and the .pbix file in the same folder structure as downloaded
  7. Open the .pbix file using Power BI Desktop
  8. If prompted, update the data source path to the local folder where the CSV files are stored
  9. Click Refresh to load the data
  10. Navigate through the dashboard pages using the built-in navigation buttons
